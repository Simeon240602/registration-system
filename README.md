# Registration System

A static front-end prototype for a complete registration system with:

- Login form with username/email, password, remember me, forgot password, and create account link
- Email/account verification screen with verification code, link, and resend code action
- User profile section with profile photo, personal info, contact info, address, password update, and edit profile actions
- Dashboard with welcome message, account information, registration status, notifications, and important links
- Admin section with user management, search, edit, approve, deactivate/delete actions, and registration statistics

## Run locally

Open `index.html` in a browser.

## Files

- `index.html` – full UI prototype
- `styles.css` – visual styling
- `script.js` – navigation interactions for the multi-screen system

## Notes

This is a static prototype, not a backend-connected app.
It focuses on the presentation and user flows for the registration system specification.
